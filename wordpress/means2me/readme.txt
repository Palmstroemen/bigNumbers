Große Beträge im Text einordnen: pro Einwohner, pro Haushalt, als Anteil am Budget und im Vergleich mit anderen Zahlen.

== Description ==

„38 Mio. Euro“ sagt den meisten wenig. Means2Me setzt ein kleines Zeichen neben den Betrag. Wer darüberfährt oder tippt, sieht zum Beispiel „9,09 € pro Haushalt in Österreich“ und auf Wunsch die nächstgelegenen Vergleichszahlen: ein Museumsbau, ein Filmbudget, ein Spielertransfer.

* Im Block-Editor: Betrag markieren oder den Cursor hineinsetzen, auf das Means2Me-Zeichen in der Werkzeugleiste tippen, Einordnungen auswählen.
* Die Werte werden beim Übernehmen fest in den Beitrag geschrieben. Ein freigegebener Text ändert sich später nicht von selbst.
* Beim Lesen lädt nur ein kleines Script (14 KB) von deiner eigenen Seite. Keine Anfrage an fremde Server, keine Cookies, kein Tracking.
* Daten für 29 Länder (EU, Schweiz, Vereinigtes Königreich, USA) aus Eurostat und amtlichen Quellen, dazu rund 590 Vergleichsbeträge mit Quellenangabe.

Der Link „Rechenweg und Quellen“ im Fenster führt zur Means2Me-App auf palmstroemen.github.io.

== Installation ==

1. Plugins → Installieren → Plugin hochladen, means2me.zip auswählen, aktivieren.
2. Einstellungen → Means2Me: Land der Leserinnen und Leser und, wenn gewünscht, die Akzentfarbe festlegen.

== Frequently Asked Questions ==

= Geht das auch im klassischen Editor? =

Im Textmodus lässt sich das HTML einfügen, das der Block-Editor erzeugt. Ein eigener Knopf für den klassischen Editor fehlt noch.

= Wie kommen neue Daten ins Plugin? =

Mit einer neuen Version des Plugins. Bereits markierte Beträge bleiben so, wie sie freigegeben wurden.
